# نظام النقل الدولي والشركة

تطبيق متكامل لإدارة شركات النقل الدولي، يربط بين إدارة الزبائن، الرحلات، الفواتير، الخزينة، والتقارير المالية مع نظام صلاحيات متكامل، وتتبع موقع الشاحنات، ومسح تذاكر المازوت بالذكاء الاصطناعي، ونظام أجور السائقين، وإشعارات وثائق الشاحنات.

## 📱 وصف المشروع

نظام إداري ذكي مصمم خصيصاً لشركات النقل الدولي، يوفر:

- **إدارة الزبائن**: تسجيل بيانات الزبائن والشركات مع إمكانية تصدير كشوف الحساب PDF
- **إدارة الرحلات**: تتبع رحلات النقل الدولي مع مسارات وحالات
- **إدارة الفواتير**: إنشاء وتتبع الفواتير مع نظام دفع ذكي وتصفية متقدمة
- **إدارة الخزينة**: متابعة الرصيد المالي وتسجيل الإيرادات والمصاريف
- **لوحة تحكم الإدارة**: تقارير مالية ورسوم بيانية وإعدادات الـ TVA
- **نظام صلاحيات**: واجهات مخصصة لكل دور (Admin, Secretary, Driver)
- **تتبع موقع الشاحنات (GPS + Maps)**: متابعة مواقع الشاحنات والسائقين على الخريطة في الوقت الفعلي
- **مسح تذاكر المازوت بالذكاء الاصطناعي**: استخراج بيانات تذاكر المازوت تلقائياً عبر التعرف على النصوص من الصور
- **نظام أجور السائقين مع البونص**: حساب رواتب السائقين وإدارة مبالغ البونص والمكافآت
- **إشعارات تلقائية لتواريخ وثائق الشاحنات**: تنبيهات مسبقة لانتهاء صلاحية وثائق الشاحنات والمقطورات

## 🛠️ الهيكل التقني (Tech Stack)

| التقنية | الاستخدام |
|---------|-----------|
| **Flutter** | واجهة أمامية للتطبيقات المحمولة والويب |
| **Supabase** | قاعدة بيانات، مصادقة (Auth)، وواجهات برمجة التطبيقات |
| **Provider** | إدارة حالة التطبيق |
| **PDF + Printing** | توليد وطباعة كشوف الحساب والفواتير |
| **Intl** | تنسيق التواريخ والأرقام |
| **Image Picker + ML Kit Text Recognition** | التقاط صور تذاكر المازوت والاستخراج الذكي للنصوص |
| **flutter_map + geolocator** | عرض الخرائط وتتبع الموقع الجغرافي للشاحنات |
| **flutter_local_notifications** | الإشعارات المحلية لتواريخ وثائق الشاحنات |

## 🗄️ بنية قاعدة البيانات

### الجداول الرئيسية:

- **`clients`**: بيانات الزبائن والشركات (الاسم، الهاتف، العنوان، المدينة)
- **`trip_orders`**: طلبات الرحلات (الزبون، المسار، السعر، تاريخ الانطلاق، الحالة)
- **`invoices`**: الفواتير (رقم الفاتورة، الزبون، المبلغ الإجمالي، المبلغ المدفوع، الحالة، تاريخ الاستحقاق)
- **`payments`**: سجل الدفعات (الزبون، المبلغ، طريقة الدفع، الرقم المرجعي)
- **`payment_invoice_allocations`**: توزيع الدفعات على الفواتير
- **`treasury_transactions`**: معاملات الخزينة (الإيرادات، المصاريف، السحوبات)
- **`app_settings`**: إعدادات التطبيق (الـ TVA)
- **`users`**: مستخدمي النظام مع الأدوار (Admin, Secretary, Driver)
- **`trucks`**: بيانات الشاحنات (اللوحة، الموديل، الحالة، الموقع الحالي)
- **`trailers`**: بيانات المقطورات (اللوحة، النوع، الحالة)
- **`drivers`**: بيانات السائقين (الاسم، الهاتف، الرخصة، الحالة)
- **`driver_salaries`**: أجور السائقين والبونص (السائق، الراتب الأساسي، البونص، الشهر، الحالة)
- **`user_documents`**: وثائق الشاحنات والمقطورات (النوع، رقم الوثيقة، تاريخ الانتهاء، المرفق)

### علاقات الجداول:

- كل **رحلة** مرتبطة بـ **شاحنة** و**سائق** و**زبون**
- كل **أجرة سائق** مرتبطة بـ **سائق**
- كل **وثيقة** مرتبطة بـ **شاحنة** أو **مقطورة**

## ⚙️ منطق العمل الذكي

### نظام FIFO لتوزيع الدفعات:
عند تسجيل دفعة من زبون، يقوم النظام تلقائياً بتوزيع المبلغ على الفواتير غير المدفوعة بالكامل وفقاً لمبدأ **أقدم فاتورة أولاً (FIFO)**:

1. يجلب الفواتير مرتبة تصاعدياً حسب تاريخ الإصدار
2. يطبق المبلغ على الفاتورة الأقدم
3. إذا كمل المبلغ الفاتورة → يُغلقها (`paid`)
4. إذا لم يكفي → يُحدّثها كمدفوعة جزئياً (`partially_paid`)
5. يسجل تفاصيل التوزيع في جدول منفصل

### التحكم الديناميكي في الـ TVA:
- تفعيل/إلغاء تفعيل الـ TVA من لوحة الإدارة
- تعديل نسبة الـ TVA حسب متطلبات العمل
- حساب تلقائي للأرباح الصافية بعد احتساب الضريبة

### مسح تذاكر المازوت بالذكاء الاصطناعي:
- التقاط صورة لتذكرة المازوت عبر `Image Picker`
- استخراج البيانات (المبلغ، التاريخ، رقم التذكرة، المحطة) تلقائياً باستخدام `ML Kit Text Recognition`
- تعبئة الحقول آلياً قبل الحفظ في قاعدة البيانات لتقليل الأخطاء اليدوية

### حساب أجور السائقين تلقائياً:
- استخراج عدد الرحلات والمسافات لكل سائق خلال الشهر
- حساب الراتب الأساسي مع إضافة مبالغ **البونص** والمكافآت تلقائياً
- تسجيل القيود في جدول `driver_salaries` مع قابلية التصدير والمراجعة

### نظام GPS وتتبع الشاحنات:
- تحديد الموقع الحالي للشاحنة عبر `geolocator` وأذونات الموقع من `permission_handler`
- عرض المسار والموقع المباشر على الخريطة باستخدام `flutter_map`
- تحديث موقع الشاحنة في جدول `trucks` لتمكين الإدارة من المتابعة اللحظية

## 🔐 الأمان والصلاحيات

نظام صلاحيات من ثلاثة مستويات:

### 1. Admin (المدير)
- صلاحيات كاملة على جميع الشاشات
- إدارة المستخدمين والإعدادات
- حذف وتعديل البيانات الحساسة
- الوصول للتقارير المالية وإعدادات الـ TVA
- تسجيل المصاريف والسحوبات من الخزينة
- إدارة الشاحنات والمقطورات والسائقين والوثائق

### 2. Secretary (السكرتيرة)
- إدارة الزبائن والرحلات والفواتير
- الاطلاع على الخزينة
- منع الوصول لإعدادات الـ TVA والتقارير المتقدمة
- أزرار الحذف معطلة

### 3. Driver (السائق)
- شاشة مخصصة تعرض الرحلات المعينة فقط
- لا يمكنه الوصول للشاشات المالية أو الإدارية
- لا يوجد شريط تنقل سفلي

## 🚀 التشغيل

### المتطلبات:
- Flutter SDK ^3.7.0
- حساب Supabase نشط
- قاعدة بيانات مُعدّة على Supabase
- أذونات الموقع والكاميرا على الجهاز (للتتبع والمسح)

### الخطوات:

1. استنساخ المشروع:
```bash
git clone <repository-url>
cd international_transport_app
```

2. تثبيت الاعتماديات:
```bash
flutter pub get
```

3. إعداد Supabase:
   - أنشئ مشروعاً جديداً على [Supabase](https://supabase.com)
   - أنشئ الجداول المذكورة أعلاه
   - استبدل الـ URL و الـ Anon Key في `lib/main.dart`

4. تشغيل التطبيق:
```bash
flutter run
```
